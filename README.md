# Shaik Zoya Mehek — Portfolio

A responsive Next.js portfolio adapted from the supplied reference portfolio and video, using a dark wine-red / burgundy / dusty-rose palette.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Production build
```bash
npm run build
npm start
```

## Deploy
Import this repository into Vercel. Framework: Next.js. Root directory: `zoya-mehek-portfolio` only if you keep the nested folder from this ZIP; otherwise use the extracted project folder as the repository root.

## Assets
- `public/images/zoya-portrait.png`: supplied studio portrait, used as the main portfolio image.
- `public/images/zoya-illustrated-portrait.png`: supplied illustrated portrait, retained as an optional visual asset.
- `public/images/zoya-character-reference.png`: supplied character turnaround reference sheet, retained as a reference asset; it is not presented as a real animation.
- `public/Zoya-Mehek-Resume.pdf`: supplied resume.

The certifications gallery includes eight image certificates and one PDF certificate. Select any card to open the original certificate in a new tab.
